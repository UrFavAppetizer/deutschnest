# Aset peta ilustrasi — Atlas Elarion V3

Folder ini untuk gambar peta fantasi yang digunakan oleh `photo-atlas.js`. Visual di situs otomatis aktif saat file dengan nama yang tepat tersedia. Jangan mengunggah ZIP ke folder ini: **ekstrak dahulu**, kemudian unggah gambar WebP-nya.

## Berkas gambar yang diperlukan
- `asteria-illustrated.webp` — gambar peta Asteria dan kerajaan tetangga (referensi dari pemain, 1448×1086).
- `avelorn-illustrated.webp` — gambar diorama Avelorn bergaya 3D (1536×1024).
- `trade-illustrated.webp` — opsional, belum dibuat; bila tidak ada tetap menggunakan peta interaktif SVG.
- `capital-illustrated.webp` — opsional, belum dibuat; bila tidak ada tetap menggunakan peta SVG.

**Petunjuk:** Di GitHub, buka folder ini → **Add file** → **Upload files** → unggah gambar `.webp` → **Commit changes**. Jika GitHub Pages aktif dari `main / (root)`, gambar akan muncul otomatis pada website Atlas. Di website juga tersedia tombol **Pilih gambar** jika ingin memakai gambar di perangkat tersebut tanpa perlu upload ke GitHub (disimpan hanya di browser itu).

## Batasan canon
Peta ilustrasi adalah bahan visual, bukan geografi baru yang otomatis sah. Penanda interaktif dan catatan canon tertulis tetap menjadi acuan. Beberapa keterangan dalam gambar arsip 3 November sudah bersifat historis: Ryujin benar-benar tiba di ibu kota Day 420 dan menghadiri upacara pada Day 423, meskipun nama resmi kota itu belum ditentukan. Posisi setiap bangunan dalam ilustrasi Avelorn harus dianggap gambaran artistik, bukan denah canon.
